📊 Dashboard Rekap Asesmen SNBP

Data tersimpan di Supabase — dapat diakses dari semua perangkat

⚙️ Panduan Konfigurasi Supabase (Lakukan Sekali)

  1. Buka supabase.com → Sign Up gratis (bisa pakai Google/GitHub)
  2. Buat New Project (nama bebas, pilih region Singapore / Asia)
  3. Masuk ke SQL Editor, jalankan query ini untuk membuat tabel:
    CREATE TABLE asesmen_siswa (
      id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
      waktu TEXT, nama TEXT, kelas TEXT, jurusan TEXT,
      cita_cita TEXT, riasec_dominan TEXT, kecerdasan_mi TEXT,
      gaya_belajar TEXT, status_casel TEXT, snbp_prodi TEXT,
      snbp_mapel TEXT, mapel_rek_minat TEXT, prodi_rekomendasi TEXT,
      karier_top TEXT, mapel_favorit TEXT, mapel_sesuai TEXT,
      kesesuaian_pct TEXT, riasec_R INT, riasec_I INT, riasec_A INT,
      riasec_S INT, riasec_E INT, riasec_C INT,
      created_at TIMESTAMPTZ DEFAULT NOW()
    );
  4. Jalankan juga query ini agar bisa diakses dari browser:
    ALTER TABLE asesmen_siswa ENABLE ROW LEVEL SECURITY;
    CREATE POLICY "allow_insert" ON asesmen_siswa FOR INSERT WITH CHECK (true);
    CREATE POLICY "allow_select" ON asesmen_siswa FOR SELECT USING (true);
    CREATE POLICY "allow_delete" ON asesmen_siswa FOR DELETE USING (true);
  5. Buka Project Settings → API, salin Project URL dan anon public key
  6. Buka file asesmen_siswa.html dan admin-dashboard.html dengan Notepad, ganti:
    const SUPA_URL = 'https://sraynffrcvabgaoogagt.supabase.co';
    const SUPA_KEY = 'sb_publishable_bdCD0RVqk-8gF2qYVwHEuw_FK-qjQ8W';
    dengan URL dan key yang sudah disalin.
